CAPM and the security market line

Explain the CAPM formula and what beta actually measures.

The capital asset pricing model says the return you should expect from a share depends on one thing only: how much market risk it carries. Risk you could diversify away earns nothing.

Key formula E(Ri)=Rf+βi(E(Rm)−Rf)

Beta is the share's sensitivity to the market, where βi=Cov(Ri,Rm)Var(Rm).

BetaWhat it meansTypical example
Below 1Moves less than the marketUtilities
Exactly 1Moves with the marketAn index tracker
Above 1Amplifies market movesAirlines, technology
Exam tip

State that only systematic risk is priced before you write the formula. It is usually worth a mark on its own.

Beyond your notes

Later empirical work found that beta alone explains returns poorly. Multi-factor models add size and value factors alongside the market.

Here is the same calculation as a small function:

python
def expected_return(risk_free, beta, premium):
    # CAPM: reward only for market risk
    return risk_free + beta * premium

print(expected_return(0.0425, 1.3, 0.055))
